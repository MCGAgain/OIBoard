# OIBoard 移动端功能对照验收清单 (FEATURE_CHECKLIST)

本清单严格对照 Web 前端实现的所有功能特性（已排除 agent 部分），作为后续阶段开发实现与阶段五最终验收的核心依据。移动端原生应用必须 100% 覆盖下列功能点。

---

## 0. 关键技术结论与边界说明

1. **关于 `local-code`（本地代码量统计）归属与处理结论**：
   - **代码归属**：`local-code` 属于 **Agent 部分**。后端中的 `POST /api/stats/local-code` 仅由 macOS 后台守护程序 `agent/oiboard-agent`（Go 编写的文件扫描器）定期扫描本地工程代码行数后推送；Web 设置中也专门有“本地代码监控服务配置与密钥 (macOS oiboard-agent)”卡片。
   - **移动端处理策略**：根据硬性约束第 3 条（“不包含 agent 部分：分析与实现时，agent 相关的模块、接口、页面一律忽略”），移动端**不实现**任何本地代码扫描、不启动常驻后台服务、不调用上报接口；在总览 KPI 中，移动端专注于纯粹的“算法刷题与比赛核心指标”（全平台 AC、今日 AC/提交、连续打卡天数、全量提交统计）。若用户服务端已有 Agent 上报的统计数据，总览页亦可只读展示其行数字段，但绝无 Agent 扫描或上报逻辑。
2. **关于真实鉴权方式的确认结论**：
   - **代码实测结论**：实际鉴权是 **HTTP Header Bearer Token** 机制，并非浏览器 Cookie/Session。
   - **调用流程**：
     - `POST /api/auth/login` 或 `POST /api/auth/register` 成功后，服务端返回 43 位 URL-safe 随机字符串 `token`。
     - 移动端将此 `token` 存储在 Jetpack DataStore 中。
     - 后续所有受保护接口（如 `/api/auth/me`, `/api/stats/*`, `/api/mistakes*`, `/api/accounts*`, `/api/settings*`）一律在 HTTP 请求头中携带：`Authorization: Bearer <token>`。
     - 服务端根据 Header 中的 Token 查询 SQLite `sessions` 表校验有效期；若未携带或已过期统一返回 HTTP 401。
     - 移动端 OkHttp 拦截器统一捕获 401 自动跳转回登录页。

## 1. 认证与网络配置 (Auth & Server Config)

- [x] **1.1 服务端地址动态配置**
  - [x] 首次启动允许用户输入后端 Base URL（默认预填 `http://10.0.2.2:8888`）。
  - [x] 本地持久化保存后端地址，并在后续所有 API 请求中复用。
  - [x] 支持在系统设置/登录页中随时修改后端服务器地址并即时生效。
- [x] **1.2 图形验证码 (Captcha)**
  - [x] 请求图形验证码接口 (`GET /api/auth/captcha`)，展示动态 Base64 验证码图片。
  - [x] 点击验证码图片即时刷新。
  - [x] 切换登录/注册模式时自动刷新验证码并清空已输入内容。
- [x] **1.3 用户登录 (Login)**
  - [x] 完整表单校验：用户名必填、密码必填、验证码必填。
  - [x] 调用登录接口 (`POST /api/auth/login`)。
  - [x] 登录成功后安全持久化 Token（使用 DataStore）与当前用户信息。
  - [x] 登录失败准确展示后端返回的错误文案（如验证码失效、密码错误），并自动刷新验证码。
- [x] **1.4 用户注册 (Register)**
  - [x] 完整表单校验：用户名 (3-32位)、密码 (>=6位)、确认密码一致性、验证码必填。
  - [x] 调用注册接口 (`POST /api/auth/register`)。
  - [x] 注册成功直接自动登录并进入主界面。
- [x] **1.5 会话鉴权与过期自动登出**
  - [x] 应用启动时调用会话自检 (`GET /api/auth/me`)，有效则直入主看板，无效或未登录进入登录页。
  - [x] 全局网络请求拦截 401 Unauthorized 状态码，自动清空 Token 并导航回登录界面，提示重新登录。
- [x] **1.6 退出登录 (Logout)**
  - [x] 调用注销接口 (`POST /api/auth/logout`) 销毁服务端 Session。
  - [x] 本地清除 Token 与用户缓存，平滑切回登录页。
- [x] **1.7 修改登录密码**
  - [x] 输入原密码、新密码、确认新密码（强制掩码显示）。
  - [x] 前端校验两遍新密码一致性与长度要求。
  - [x] 原生二次确认弹窗防误触，调用密码变更接口 (`POST /api/auth/password`)。
