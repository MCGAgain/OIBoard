# OIBoard 项目架构与功能分析报告 (PROJECT_ANALYSIS)

## 1. 项目整体概述

OIBoard 是一个面向算法竞赛选手的多平台刷题与比赛数据聚合看板系统，能够自动同步并汇聚 Codeforces、AtCoder、洛谷 (Luogu)、AcWing 以及力扣 (LeetCode) 等多个主流 OJ 平台的提交记录、通过题目、算法标签与比赛日程，并提供艾宾浩斯记忆遗忘曲线错题本与多维数据可视化。

现有系统采用典型的前后端分离单体架构：
- **后端**：基于 Python FastAPI 提供的轻量级 RESTful API 服务，依赖 SQLite 3 (WAL 模式) 实现单机高效并发持久化存储。
- **前端**：采用现代化的 Vue 3 (Composition API) 单页应用，结合 Apache ECharts 5.5 进行图表渲染，配合 Tailwind CSS 实现 Apple 质感的极简深浅色自适应界面。
- **采集端**：内置异步非阻塞 HTTP 爬虫同步引擎，结合多账号轮询与 Tampermonkey 油猴实时秒级推送插件。
- **Agent**（规则约束忽略）：包含一个用于扫描本地代码行数并推送的 Go 守护进程，移动端分析与实现中已严格排除。

## 2. 技术栈与环境依赖

| 分层 | 技术选型 | 版本/规范 | 详细说明 |
| :--- | :--- | :--- | :--- |
| **后端语言** | Python | 3.10+ | 异步协程驱动 |
| **API 框架** | FastAPI | >= 0.110.0 | 基于 Starlette 与 Pydantic V2 构建高性能 ASGI 接口 |
| **ASGI 服务器** | Uvicorn | >= 0.28.0 | 高性能单进程异步网络驱动 |
| **数据库** | SQLite 3 | WAL Mode | 单文件嵌入式存储 (`data/oiboard.db`)，高并发读写分离，外键级联约束 |
| **网络请求/爬虫** | HTTPX + BeautifulSoup4 | 最新稳定版 | 支持 HTTP/2、SOCKS5/HTTP 代理隧道与 DOM 树解析 |
| **认证与安全** | PBKDF2-HMAC-SHA256 | 260,000 次加盐 | 安全防时序攻击密码哈希，Bearer Token 会话隔离 |
| **验证码** | Pillow (PIL) | 最新稳定版 | 内存动态生成带旋转角度、干扰线、随机噪点的 Base64 图形验证码 |
| **Web 前端** | Vue 3 + Tailwind CSS + ECharts | 3.x / 5.5 | 扁平响应式单页应用 (`static/index.html` + `static/app.js`) |
| **辅助采集** | Vite + TypeScript | 5.x / 5.3+ | 油猴脚本 `oj-tracker.user.js`（移动端原生直连后端，无需此组件） |

## 3. 前后端划分与部署运行方式

### 3.1 目录划分
```text
OIBoard/
├── main.py              # FastAPI 核心入口、所有 API 路由注册与静态托管
├── auth.py              # PBKDF2 密码哈希、密码校验与安全随机 Token 生成
├── captcha.py           # 内存噪点图形验证码生成器与 5 分钟滑动过期存储
├── db.py                # SQLite 数据库完整读写层与统计分析聚合逻辑
├── scheduler.py         # 异步定时轮询调度引擎 (支持多账号同步与比赛抓取)
├── run.py               # 命令行启动脚本 (支持自定义端口)
├── fetchers/            # 各 OJ 平台爬虫与连通性验证模块 (CF, AtCoder, 洛谷, AcWing, 比赛)
├── backend-spec/        # 规范化外部提交接收路由与核实 Worker (oj-tracker 协议)
├── static/              # 静态 Web 资源 (index.html, app.js, style.css, favicon.svg)
├── data/                # SQLite 数据库存放目录 (oiboard.db)
└── agent/               # [忽略] Go 编写的本地代码监控 Agent 守护进程
```

### 3.2 启动方式与默认端口
- **本地开发/运行方式**：
  ```bash
  python run.py [端口号]
  ```
- **默认监听端口**：`8888`（若命令行指定或指定环境变量 `PORT` 则优先读取，生产部署常为 `2053`）。
- **默认根路由**：`http://127.0.0.1:8888/` 挂载 `static/index.html`。
- **默认管理员账户**：
  - 用户名：`admin`
  - 密码：`admin123`
- **Android 模拟器访问地址**：
  - 宿主机 `127.0.0.1:8888` 映射到模拟器内网地址为 `http://10.0.2.2:8888`。

## 4. 前端所有页面 / 路由 / 功能模块清单

Web 前端为单 Activity 架构的纯前端 Tab 切换（无 Vue Router，通过响应式状态 `currentTab` 驱动）。所有核心功能模块清单如下（排除 agent 后）：

1. **登录与注册模态面板 (Auth Modal)**：提供用户名/密码与图形验证码的登录与注册切换、会话持久化、Token 过期拦截。
2. **顶栏导航与控制条 (Header Bar)**：展示当前视图标题、实时同步徽标、外观模式切换（自动/浅色/深色）、当前用户与管理员标识、多平台（CF/AT/LG/AW/LC）实时连接健康状态指示灯。
3. **数据总览看板 (Tab: Overview)**：
   - *KPI Bento 卡片组*：全平台通过题数与各平台分布、今日通过数与圆环通过率、连续打卡天数、全量提交统计与上次同步时间。
   - *近期比赛快捷卡片*：置顶展示未来即将开赛的 3 场比赛（平台徽标、开赛时间、动态倒计时与详情外链）。
   - *年度贡献热力图 (Heatmap)*：支持年份选择与多平台（全平台/CF/AT/LG/AW/LC）快速切换的 365 天打卡格子图。
   - *统计分析工作台 (Analytics Charts)*：支持 4 类视图切换：① 累计通过 (Climbing Curve) 支持高斯核平滑与原始阶梯；② 每日提交 (Daily Effort) 堆叠柱状；③ 算法标签画像 (Tags) 横向柱状；④ 平台题目占比 (Platforms) 环形占比。
4. **比赛日历列表 (Tab: Contests)**：
   - 包含多平台过滤（全部/CF/AT/LG）、状态过滤（全部/进行中 CODING）、关键词实时搜索、手动一键重新抓取比赛。
   - 表格/卡片式展示比赛平台、名称、赛制规则、开赛时间、比赛时长、实时跳动倒计时（秒级递减）以及比赛页面直达外链。
5. **全量提交流 (Tab: Submissions)**：
   - 组合筛选：日期预设（全部/今天/近7天/近30天/今年）与自定义日期区间；平台筛选；状态（AC/未通过）；算法标签下拉；题目/题号模糊搜索；一键重置。
   - 提交表格/卡片：平台徽章、题号、题目名称、判题结果 (AC/WA/TLE/MLE等状态色)、难度标签、语言、相对时间戳（如 2小时前）、官方提交记录外链。
   - 错题关联：一键将任意提交记录添加到错题集（若已收录则显示高亮“已入错题”并可打开查看）。
   - 分页器：前后翻页与总数统计。
6. **专属错题集工作台 (Tab: Mistakes)**：
   - *KPI 进度统计卡*：全部错题数、待复习（到期高亮红标）、训练中（按周期强化）、已掌握。
   - *多维检索工具栏*：状态过滤（全部/待复习/训练中/已掌握）、平台过滤、标签过滤、多字段搜索（题号/标题/考点/笔记）、排序规则切换（最新提交时间/下次复习时间/复习次数）。
   - *收录错题按钮*：主动弹出添加错题弹窗。
   - *错题卡片流*：展示题目元信息、难度、标签、核心考点/错因分类、艾宾浩斯复习轮次与下次复习倒计时/逾期状态标签。
   - *卡片快捷动作*：打卡复习（自动推进艾宾浩斯轮次）、掌握状态一键切换（掌握与恢复复习）、编辑错题、删除错题。
   - *查看思路笔记与代码弹窗 (View Note Modal)*：展示题目的深度解析、考点分析与完整代码，支持打卡复习与跳转编辑。
   - *添加/编辑错题弹窗 (Mistake Edit Modal)*：录入/修改平台、题号、标题、难度、标签、考点、笔记与题面 URL。
7. **平台设置与账号管理 (Tab: Settings)**：
   - *多平台多账号管理*：分别展示 Codeforces、AtCoder、洛谷、AcWing、力扣绑定的多账号列表（显示用户名、别名、主账号徽标）。
   - *账号操作*：设为主账号、编辑账号凭据（Cookie/别名）、删除账号、单账号即时抓取同步、独立测试连通性。
   - *添加账号弹窗 (Account Modal)*：选择平台，输入用户名/Handle、Cookie（洛谷/AcWing 鉴权）、备注别名，可选直接设为主账号，支持弹窗内连通性测试。
   - *全局同步与代理配置*：配置后台定时轮询间隔（分钟）、冲刺模式高频轮询切换、出站 HTTP/SOCKS5 代理配置、一键保存并触发全局同步。
   - *账号密码安全设置*：修改登录账户密码（原密码、新密码、确认密码）。
   - *退出登录*：注销当前会话并清空本地缓存。
