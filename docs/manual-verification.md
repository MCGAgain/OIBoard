# OIBoard 实时更新与前端性能优化 手工验证清单 (Manual Verification Checklist)

本文档提供在 Chrome 浏览器中对 `refactor/realtime-and-perf` 分支与 `main` 分支进行对照验证的完整操作指南与核验清单。

## 一、双端口本地对照环境搭建 (Git Worktree)

通过 `git worktree` 可以在本地同时检出 `main` 分支与 `refactor/realtime-and-perf` 分支，分别运行在不同端口进行 1:1 双屏或双窗口实时对比。

### 1.1 检出 main 分支到独立工作区
在项目根目录执行：
```bash
# 在上一级目录创建 OIBoard-main 独立工作区（关联 main 分支）
git worktree add ../OIBoard-main main
```

### 1.2 启动两个独立服务
打开两个终端窗口：

**终端 1（对比基准：main 分支，运行在 8000 端口）**：
```bash
cd ../OIBoard-main
../OIBoard/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

**终端 2（优化目标：refactor/realtime-and-perf 分支，运行在 8001 端口）**：
```bash
cd /Users/Zhuanz/Documents/Program/OIBoard
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8001
```

> **注意**：两边均使用本地 SQLite 数据库测试副本，数据互不干扰。在 Chrome 中分别打开：
> - 基准对比：`http://127.0.0.1:8000`
> - 优化验证：`http://127.0.0.1:8001`

### 1.3 测试完成后的清理命令
验证完毕后，可随时移除临时工作区：
```bash
git worktree remove ../OIBoard-main
```
